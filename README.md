# AI-Driven Production Scheduling & Planning

MVP for a solo course project using **Forecast + Rules + GenAI**.

## Run locally

```bash
pip install -r requirements.txt
python 01_data_preparation.py
python 02_train_model.py
python 03_scheduling_engine.py
python 04_forecast.py
python 05_genai_report.py
streamlit run app.py
```

Open the local Streamlit URL shown in the terminal.

## Optional GenAI

Create `.env`:

```text
OPENAI_API_KEY=your_api_key_here
```

Without an API key, the dashboard still works and uses a deterministic fallback report. With an API key, the report is generated by an LLM.

## Project flow

Data Preparation → Demand Forecast → Risk Model → Rules-based Scheduling → KPI/Gantt → GenAI Report → Streamlit Dashboard
